# Enterprise Network Configuration & Simulation

## Project Overview
This project demonstrates the design and configuration of a simulated enterprise network environment using Cisco Packet Tracer. The goal was to establish reliable communication between different network devices using industry-standard networking protocols.

## Technologies & Tools Used
* **Simulation Tool:** Cisco Packet Tracer
* **Networking Concepts:** IP Addressing, Routing, Switching
* **Protocols:** TCP/IP, ICMP

## Key Features & Implementation
* **Network Topology Design:** Designed a network topology including routers, switches, and end devices (PCs).
* **IP Addressing:** Assigned IPv4 addresses to all devices and configured subnets.
* **Routing & Switching:** Configured routers to enable communication between different networks and configured switches for local device connectivity.
* **Troubleshooting:** Tested connectivity using `ping` commands and resolved network issues.

## How to Run
1. Download and install **Cisco Packet Tracer** (version 8.x or higher).
2. Download the `.pkt` file from this repository.
3. Open the `.pkt` file in Cisco Packet Tracer.
4. You can test the connectivity by opening the command prompt on any PC and pinging another device's IP address.
